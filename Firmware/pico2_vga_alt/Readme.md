# Planck 6502 Pico-VGA Firmware (alternative)

Firmware for the Pico-VGA card used in the Planck 6502 homebrew computer.

**This firmware is in an early stage of development; please use pico2_vga instead.**

This version uses [PicoVGA cmake](https://github.com/codaris/picovga-cmake), which should provide much greater capabilities for the graphics card.
